# Горячие клавиши Niri

Niri — скроллируемый тайлинговый Wayland-композитор. `Mod` = Super.

## Фокус
| Хоткей | Действие |
|---|---|
| Mod+Стрелки или H/J/K/L | Фокус на колонку/окно |
| Mod+Home/End | В начало/конец колонки |

## Перемещение
| Хоткей | Действие |
|---|---|
| Mod+Shift+←→ или H/L | Переместить колонку |
| Mod+Shift+↑↓ или K/J | Переместить окно внутри колонки |

## Ресайз
| Хоткей | Действие |
|---|---|
| Mod+R | Ширина колонки |
| Mod+Shift+R | Высота окна |
| Mod+Ctrl+R | Сбросить высоту |
| Mod+F | Развернуть колонку |
| Mod+Shift+F | Фуллскрин |
| Mod+Shift+T | Плавающее окно |

## Воркспейсы
| Хоткей | Действие |
|---|---|
| Mod+1-4 | Переключиться на воркспейс |
| Mod+Shift+1-4 | Переместить колонку на воркспейс |
| Mod+Ctrl+↑↓ | Переместить на воркспейс |
| Mod+Ctrl+J/K | Фокус между воркспейсами |

## Запуск
| Хоткей | Действие |
|---|---|
| Mod+Return | Терминал |
| Mod+D | Лаунчер (fuzzel) |
| Mod+B | Браузер |

## Система
| Хоткей | Действие |
|---|---|
| Mod+Shift+E | Выйти из niri |
| Print | Скриншот всего экрана |
| Mod+Shift+S | Скриншот области → аннотация |

## Язык
| Хоткей | Действие |
|---|---|
| Shift+Alt | Переключить раскладку |

## Расположение конфига
- `~/.config/niri/config.kdl`
- Перезагрузка: `niri msg action load-config-file`
- Focus ring: `layout { focus-ring { width 2 active-color "#CBA6F7" inactive-color "#313244" } }`

## Подводные камни
- Парсинг KDL строгий — невалидные блоки приводят к тихому отклонению конфига
- Держи рабочий бэкап: `~/.config/niri/config.kdl.bak`
- Бинарникам из `nix profile` нужны ПОЛНЫЕ пути в `spawn-at-startup`
